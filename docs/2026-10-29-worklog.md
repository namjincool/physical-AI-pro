# 2026-10-29 작업 과정

등록일: 2026-10-30. 아래는 실제 수행한 과정의 정리이며 커밋 날짜를 과거로 바꾸지 않습니다.

1. 첨부한 MuJoCo 실습 가이드를 읽고, 잘려 있는 Python 코드를 확인했습니다.
2. 사용자 OpenCrab Physical AI 팩에서 상태/입력 구분, 초기조건·단위·실패·재현 기록
   근거를 조회했습니다. 팩의 원칙과 이번 코드·측정 결과의 출처를 구분했습니다.
3. Windows 11과 Python3.13.7을 확인하고 프로젝트 전용 환경을 구성했습니다.
   임시 폴더 쓰기 제한을 작업 폴더 사용으로 해결하고 네트워크 권한 승인 후 설치했습니다.
4. 단일 회전관절 XML과 PD 제어 루프를 구현했습니다. 베이스는 시각용으로만 사용하며
   각도 직접 대입 대신 모터 토크와 실제 `mj_step`을 사용했습니다.
5. A45도, B90도, C낮은P, D낮은D 및 E무제어를 독립된 초기조건에서 실행했습니다.
6. CSV에 스텝 전·후 상태와 입력, JSON에 조건·평가·해시를 저장하고 실제 그래프를 생성했습니다.
7. 13개 테스트 통과와 의존성 검사를 확인했습니다. 커버리지 수치는 확보하지 못해 주장하지 않습니다.
8. 45도 GUI를 실제 초기화해 1500스텝 완료를 확인했습니다. 별도의 MuJoCo Renderer로
   최종 상태 이미지를 생성했습니다. 데스크톱 스크린샷이나 AI 생성 이미지가 아닙니다.
9. 코드 해설, 수행 결과, 파일 목록과 무결성 기록을 작성하고 로컬 날짜 폴더로 정리했습니다.
   로컬 정리본은 복사 검증 기록을 포함해 38개 파일이었습니다.
10. 10월30일 GitHub용 등록본을 작성했습니다. 로컬 절대경로·비공개 팩 ID는 제외하고
    코드·모델·실험 CSV 및 성능 수치를 보존했습니다. 기존 로컬 원본은 변경하지 않았습니다.
